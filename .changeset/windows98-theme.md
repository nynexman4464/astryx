[feat] Add `@astryxdesign/theme-windows98`, a Windows 98 theme. Light mode is the "Windows Standard" appearance and dark mode is the Windows 9x "Slate" scheme, which keeps light blue-grey controls and black text rather than inverting to a modern dark palette. Chrome follows the Win32 edge model with separate raised (window), raised (push button), sunken, and etched edges; nested panels resolve the etched edge through the cascade. Fonts are referenced by name and not bundled.
