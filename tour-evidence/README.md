# Tour: screenshots and contrast

Captured from the `Core/Tour` stories in Chromium with `capture.mjs`
(serve the built Storybook on `127.0.0.1:6111`, then run the script).

- `first-step`, `middle-step`, `last-step`, `focus-visible`, `backdrop`,
  `centered`: Neutral and Stone, light and dark, at 900 by 520.
- `narrow-touch-*`: a 390-pixel viewport with a touch pointer.
- `forced-colors`: forced colors active.
- `contrast.json`: contrast ratios computed from the rendered colors.
